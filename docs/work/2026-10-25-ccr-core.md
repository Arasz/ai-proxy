# CCR preview and retrieval core

PR [#66](https://github.com/Arasz/ai-proxy/pull/66) adds the pure operations for deterministic tool-result previews and `proxy_retrieve` answers. `CcrPreview.Build` selects original lines within a budget and identifies hidden ranges. `CcrRetrieval.Answer` validates tool arguments and returns numbered lines, pattern windows, or the exact original after a header.

This is an inactive implementation slice. The host does not call these operations, inject the tool, retain originals, or intercept retrieval calls. There is no runtime release or version change here. Activation still requires the design gate in [#64](https://github.com/Arasz/ai-proxy/pull/64), host integration, readable originals before hints, streaming and thread handling, and the acceptance gates in the [activation record](2026-10-24-csharp-reducer-activation.md).

`CcrOptions.Default` preserves the draft's provisional 3,000-token minimum, 1,000-token preview and 4,000-token retrieval cap. All three are configurable. Owner feedback on 2026-10-25 annotates the minimum/preview question with “1500 tokens” and the retrieval cap with “3000”. The design gate must reconcile which preview number changes and supply the resolved settings before activation; these defaults are not approved runtime settings.

## Progress and validation

The parent task graph is `aip-whole-request-compression-and-retrieval`, step `ccr-implement`. This slice supplies evidence for its `deterministic` criterion. Its `roundtrip` criterion stays outstanding until an integration test proves the host answers retrieval inside one client response. The linked finish graph is `aip-finish-ccr-core-review`.

The unit suite covers repeatable and culture-independent previews, content hashes, line coverage, budgets, retrieval caps, malformed arguments and exact whole-text recovery. Independent review found malformed Unicode arguments escaping the error contract and pattern windows splitting surrogate pairs. Regression tests exercise those cases and the existing preview cut boundary. Mutation QA verifies that changing whole retrieval to trim the original makes the exact-text test fail.
