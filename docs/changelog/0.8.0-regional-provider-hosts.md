# 0.8.0: regional provider hosts

**Released:** 2026-10-24
**PRs:** #46

ai-proxy now recognizes the regional API hosts that OpenAI and OpenRouter document for data
residency: `us.`, `eu.`, `gb.`, `ca.`, `au.`, `jp.`, `kr.`, `sg.`, `in.` and `ae.api.openai.com`,
and `eu.openrouter.ai`. Before, a client set to one of these base URLs went through an opaque
tunnel, so its requests were neither captured nor compressed. Each request still goes to the
regional host it addressed.

Matching stays exact. `mcp.openrouter.ai` and any prefix the providers don't document remain
pass-through. The list with its sources is in
[environment variables](../reference/environment-variables.md).
