# 0.35.3: preview union and required seams

Internal refactor, wave 3 of [ADR 0022](../adr/0022-absent-values-are-union-cases-not-null.md).
No behaviour change: log text, JSON output, HTTP answers, SQL and gain database values are the
same. Shipped in [#173](https://github.com/Arasz/ai-proxy/pull/173).

## Changes

- **A preview decision is a union.** `CcrPreviewBuilder.Build`, `CcrPreviewer.PreviewAsync` and
  the pipeline return `CcrPreview` or `NoCcrPreview`, not null.
- **The code view returns its own fallback.** `SourceCodeCompressionHandler.View` gives the
  blank-line text when no code view applies; its caller has no `??`.
- **Required seams.** `GuardCommand` takes both delegates as required parameters; the error for a
  missing recovery provider is gone, as production never reached it. The internal
  `TitaniumProxyService` constructor takes non-nullable seams, and the public one passes the
  production defaults.
- **Null kept on purpose.** Store lookups, request-body scans and the file-read path keep their
  nullable values (ADR 0022 rules 10 to 12).

Nothing to do.
