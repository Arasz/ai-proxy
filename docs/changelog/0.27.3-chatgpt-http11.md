# 0.27.3: chatgpt.com tunnels use HTTP/1.1

A Codex request through `ai-proxy harness` could fail, even partway through a working session, with `stream disconnected before completion: error sending request`, while the proxy logged `frame of type Data exceeded the maximum accepted frame size`. The proxy passed on `chatgpt.com`'s larger HTTP/2 frame size, then rejected frames that used it. Codex never saw the real answer, such as `The 'gpt-6.1-terra' model is not supported`.

Credentialed `chatgpt.com` tunnels now use HTTP/1.1, so the frame error is gone and upstream errors reach Codex. Other hosts keep HTTP/2. See [ADR 0013](../adr/0013-pin-harness-only-hosts-to-http11.md).
