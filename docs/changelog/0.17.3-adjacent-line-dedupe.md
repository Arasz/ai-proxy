# 0.17.3

The line reducer no longer rewrites source code. It used to drop every line that had appeared
anywhere earlier in a tool result, so a file read through a shell (`cat`, `sed`, `git show`)
lost its repeated braces, returns and namespaces before the model saw it. Now it drops a line
only when it exactly repeats the line directly above it, indentation included.

The same rule applies wherever the reducer runs: prose, logs, shell transcripts, and JSON or
XML that fails to parse. Logs whose repeats are not adjacent shrink less than before.
