# 0.9.0 - Settings move to the `Proxy` configuration section

**Breaking.** The flat `PROXY_*` variables are replaced by the standard .NET configuration section
`Proxy`, which the host binds with its default configuration providers. A setting that still uses
an old name is ignored.

| Before | Now |
|---|---|
| `PROXY_PORT` | `PROXY__PORT` |
| `PROXY_COMPRESSION=on` | `PROXY__COMPRESSION__ENABLED=true` |
| `PROXY_COMPRESSION_DB` | `PROXY__COMPRESSION__DATABASE` |
| `PROXY_COMPRESSION_MINIMUM` | `PROXY__COMPRESSION__MINIMUM` |
| `PROXY_CAPTURE=on` | `PROXY__CAPTURE=true` |
| `PROXY_ROOT_CERTIFICATE_PASSWORD` | `PROXY__ROOTCERTIFICATEPASSWORD` |

- A switch takes `true` or `false`; `on` is no longer accepted.
- An empty `PROXY__PORT` is unset and keeps `8080`; a port outside 1 to 65535 still stops startup,
  with an error naming `Proxy:Port`.
- A `PROXY__COMPRESSION__MINIMUM` that is not a whole number stops startup instead of being ignored.
- The service registrations moved into `AddProxy` and `UseProxy` extension methods; the
  request-handling behaviour is unchanged.
