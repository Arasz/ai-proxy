# 0.12.0 - Python code view

A whole Python file that a tool call read now gets the same code view as C# files in
[0.11.0](0.11.0-csharp-code-view-on-by-default.md): comments and `import` lines removed, a
`[proxy view <id>: ...]` line at the end, and the exact text back through `proxy_retrieve`.

- **What stays.** Docstrings and other strings, f-string fields, and directive comments (`#!` on line
  one, the encoding cookie, `# type:`, `# noqa`, `# pragma:`, `# pylint:`, `# mypy:`, `# fmt:`).
- **Fallback.** A file the Tree-sitter grammar cannot parse cleanly, or a machine where its native
  library does not load, keeps the blank-line reduction.
- **Switch.** `PROXY__COMPRESSION__CODEVIEWS=false` turns off both the C# and the Python views.

Not covered: JavaScript and TypeScript views.
