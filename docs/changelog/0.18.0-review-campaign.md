# 0.18.0

The first wave of fixes from the project-scope review
([record](../work/2026-10-30-project-scope-review.md), [plan](../work/2026-10-30-project-scope-review-plan.md)).

**Startup is strict now. This can stop a start that used to work.**

- An unknown command or a stray flag (`ai-proxy --verison`, `ai-proxy gian`) prints usage and exits 2.
  It no longer starts the proxy and sets the system proxy.
- `ai-proxy --version` prints the version.
- An unknown `Proxy:*` setting stops startup and names the key. That includes a stray
  `PROXY__*` environment variable left over in your shell. Remove it or fix its spelling.
- A second `ai-proxy` start says which instance is already running (its pid and port) and points
  at `ai-proxy --restart`.

**Local data no longer grows without bound.**

- Requests, their chunks, retrieval originals and failed queue rows in `content.db` are deleted
  after 14 days. `GET /content/{requestId}` answers 404 for an expired record.
- When capture is on, its rows are deleted after 14 days. Capture also pauses once
  `PROXY__CAPTUREMAXBYTES` (default 1 GB of pages in use) is reached, and resumes after old rows go.
- `content.db` is created readable by you only (`0600`), and an existing file is tightened.
- A queue row that cannot be read is set aside with its error instead of stopping every later
  write.

**Compression sends less.**

- Rewritten tool output is no longer escaped. `<`, `&`, `'` and non-ASCII characters go out as
  they are, not as `<`-style escapes that cost tokens.
- A JSON tool result with a broken surrogate escape falls back to the line reducer instead of
  being recorded as a failure on every turn.

**The retrieval relay is safer.**

- If the provider never sends response headers, the relay gives up after 10 minutes with a 504
  instead of waiting forever. A client that disconnects first still holds the request until then,
  because Titanium does not expose the client's cancellation.
- The relay no longer follows redirects. A 3xx reaches the client, so your API key is not
  re-sent to another host.

**`ai-proxy gain` reads more honestly.**

- The summary shows net savings (saved − retrieved − the injected tool's cost) and saved/net
  percentages beside the gross figure, with thousands separators. CSV and JSON keep raw numbers
  and add two columns at the end.
- A request whose only change is the injected `proxy_retrieve` tool is recorded as `ccr.tool`,
  not as `unchanged` with negative savings.
- `gain --project` with no requests explains why: the `X-Ai-Proxy-Project` header, set by
  `ai-proxy harness`.
- Help no longer lists the rtk-only unavailable flags (they still parse), and every flag has a
  description.

**Docs and CI.**

- ADR 0008 replaces parts of ADR 0005: retrieval previews are on for every content kind, and
  the per-kind activation gate is withdrawn.
- The README shows port 8080 again.
- `build-bdd` now checks docs, evidence anchors, action pins and this changelog, and runs on
  docs-only changes too.
- A release without its changelog entry is refused.
- Evidence anchors name the symbol they point at (`path:line#Symbol`), and the check fails when a
  line moves.
- Four tests that were skipped now run (restart identity checks, upstream drop, marker waits),
  and a new test keeps the `mcp`, `gain` and client code away from storage and SQLite.
