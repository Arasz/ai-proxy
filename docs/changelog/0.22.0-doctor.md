# 0.22.0: ai-proxy doctor

When an agent skips the proxy, the cause is rarely obvious. The proxy may be stopped, the
shell may point at another proxy, or the root certificate may be wrong. `ai-proxy doctor`
now checks all of that in one go and changes nothing.

It runs four checks. The API check asks `/health` which product and version answers. The
inspection check opens a tunnel through the proxy to a provider host, completes only the TLS
handshake, and confirms the certificate chains to the published root. The root check reads
`root-ca.pem` and flags a private key, a root that is not limited to the provider hosts, an
expired root, or one that expires within 30 days. The environment check compares
`HTTPS_PROXY` and `HTTP_PROXY` with the proxy, and never prints credentials or query strings.

The exit code is 0 when everything passes, 1 when anything fails and 2 when there are only
warnings or unknowns. An offline upstream never counts as a failure. `--format json` prints
the same report for scripts.

`/health` keeps its `status` field and now adds `product` and `version`.
