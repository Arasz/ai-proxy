# 0.10.0 - CCR runtime, on by default

Recoverable compression (CCR, [ADR 0005](../adr/0005-tool-result-previews-with-in-request-retrieval.md); [implementation plan](../work/2026-10-25-ccr-runtime-plan.md)) now runs, and
compression is on by default.

- **Defaults change.** `Proxy:Compression:Enabled` and the new `Proxy:Ccr:Enabled` default to
  `true`. Set `PROXY__COMPRESSION__ENABLED=false` to forward every request untouched, or
  `PROXY__CCR__ENABLED=false` to keep the reducers without previews.
- **Previews.** On a streamed Anthropic `/v1/messages` request that defines tools, a tool result
  whose reduced text is still at least 3,000 estimated tokens is sent as a preview: original lines,
  signal lines first, at most 1,500 tokens, with an id. A thread's original is written to the
  content database before its preview is sent; if that write fails, the region goes out with its
  reducer output and no preview.
- **Tool.** `proxy_retrieve` is appended as the last tool of every such request (thread `create`
  and stateless), so `tools` does not change within a conversation.
- **Retrieval loop.** The proxy sends these requests upstream itself and answers the client with one
  streamed message. Text and thinking stream through as they arrive; tool calls are held until the
  message ends. A `proxy_retrieve` call is answered by the proxy and a follow-up goes upstream (a
  thread `continue` from the retrieving message, or the stateless request plus the assistant message
  as received). A client tool called in the same message gets an `is_error` result asking the model
  to call it again. Three rounds are answered; a fourth gets `limit_reached`; a fifth call ends the
  turn with an `error` event. The client sees `ping` events while a follow-up runs.
- **Thread ledger.** Each response of a thread created with the tool is recorded. A later `continue`
  naming a message that had hidden turns is pointed at the last of them. If the ledger cannot be
  read, the client gets `529 overloaded_error` and retries.
- **Storage.** The content database gains `ccr_original` and `ccr_thread` (schema version 2).
  Rows are evicted 14 days after they are written.
- **Capture.** A relayed exchange is captured as before. Its usage carries the summed output tokens,
  and its stages carry `ccr.round-N` timings. Each retrieval is logged (event 1601).

Not covered: non-streamed requests, providers other than Anthropic, and the per-kind activation
gate. Every kind previews.
