# 0.28.4: name the remaining gain layers and relabel old rows

This finishes the layer names that 0.28.2 introduced.

- Non-model traffic, such as telemetry, is recorded under layer `none` instead of `unknown`.
- Recalls and follow-ups made inside a request take pipeline `ccr`, as `retrieve_original` recalls already did. Combined with 0.28.2, all retrieval cost now sits under layer `retrieval` and pipeline `ccr`.
- The first start on 0.28.4 rewrites the existing ledger once, so old and new rows agree. It names each `unknown` layer from the stored rule (`unchanged` and `ccr-plan-failed` become `none`, `ccr.tool` becomes `ccr_tool`, any other rule becomes `tool_result`) and moves recalls and follow-ups to `retrieval` and `ccr`. The rewrite only touches rows that are not yet in that state, so running it again changes nothing.

`unknown` is now left for values the proxy really does not know.
