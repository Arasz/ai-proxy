# 0.14.0 - JavaScript and TypeScript code views

A whole JavaScript or TypeScript file that a tool call read now gets the code view that C#
([0.11.0](0.11.0-csharp-code-view-on-by-default.md)) and Python ([0.12.0](0.12.0-python-code-view.md))
files get: comments and `import` lines removed, a `[proxy view <id>: ...]` line at the end, and the
exact text back through `proxy_retrieve`.

- **Files.** `.js`, `.mjs`, `.cjs`, `.jsx`, `.ts` and `.tsx`. `.jsx` is now recognized as a JavaScript
  source file; before, a `.jsx` read was not treated as source code.
- **Fallback.** A file the Tree-sitter grammar cannot parse cleanly, or a machine where its native
  library does not load, keeps the blank-line reduction.
- **Comments tools read.** Views now keep Python `# pyright:`, `# ruff:`, `# isort:`, `# nosec`,
  `# pyre-` and `# fmt: skip`, and JavaScript/TypeScript `prettier-ignore`, `biome-ignore` and
  `istanbul`/`c8`/`v8 ignore` comments, so a line rewritten from the view keeps its suppression.
- **Package exports.** A Python `__init__.py` keeps its imports, since they are what the package exports.
- **Switch.** `PROXY__COMPRESSION__CODEVIEWS=false` turns off every code view.
