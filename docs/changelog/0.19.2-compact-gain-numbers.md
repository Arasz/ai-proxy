# 0.19.2: gain numbers fit the terminal

The `ai-proxy gain` summary table was 128 columns wide. In a narrower terminal, or whenever the
output was piped, the table wrapped every cell, and a count such as `261,175,524` split into
`261,17` and `5,524` on two lines.

Table numbers under 10,000 still print exactly. Larger ones print with one decimal and a K, M or B
suffix, so 261,175,524 shows as `261.2M`. The summary headers drop the word "tokens" and the title
carries it instead. The table is now 89 columns wide and fits a 100-column terminal on one line per
row. At 80 columns the headers wrap at word breaks, but no number splits.

The other-traffic line keeps exact numbers. `--format json` and `--format csv` keep exact raw
values for scripts.
