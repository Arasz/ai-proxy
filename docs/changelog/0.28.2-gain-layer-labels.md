# 0.28.2: every gain layer is named

`ai-proxy gain --by-layer` listed most requests under `unknown`, although the proxy knew what it did to them. Each request now records one of these layers:

- `tool_result`: the proxy reduced tool output.
- `ccr_tool`: the only change is the injected `proxy_retrieve` definition, so the row shows that cost on its own.
- `none`: the request went upstream unchanged, or was refused because the retrieval ledger was unavailable.
- `retrieval`: recalls and the follow-up requests that answer them, whether they come from `proxy_retrieve` or the `retrieve_original` MCP tool.

`unknown` is now left for values the proxy really does not know. Rows recorded before 0.28.2 keep the layer they were written with; `--by-rule` still tells them apart.
