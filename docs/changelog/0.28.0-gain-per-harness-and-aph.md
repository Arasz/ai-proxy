# 0.28.0: gain per harness and the aph shortcut

`ai-proxy gain` now shows one block each for `claude`, `codex` and `other`, instead of one summary table. Non-model traffic is listed under `other`. JSON output gains a `harnesses` list, and CSV is unchanged.

The harness comes from the provider: Anthropic traffic is `claude`, OpenAI traffic is `codex`, and everything else is `other`. Existing history is grouped the same way. A script calling the Anthropic API therefore counts as `claude`.

`ai-proxy shortcut` writes an `aph` launcher beside `ai-proxy`, so `aph claude` runs `ai-proxy harness claude`. It refuses to replace a file it did not create. `ai-proxy shortcut --remove` deletes the launcher, and `dotnet tool uninstall` does not.
