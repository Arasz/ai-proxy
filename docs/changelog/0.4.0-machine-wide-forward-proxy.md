# 0.4.0: machine-wide forward proxy

**Released:** 2026-10-23
**PRs:** #19

ai-proxy now uses the current user's system HTTP and HTTPS proxy settings, restores the
previous settings on normal shutdown, and needs no upstream or pass-through configuration.
It recognizes the standard OpenAI, Anthropic, Google Gemini, and OpenRouter API hosts.

HTTPS is inspected only for those provider hosts using a per-user root certificate. Other
HTTPS destinations remain tunneled, and other HTTP traffic passes through unchanged. The
caller continues to supply provider credentials. This replaces the previous configured
reverse-proxy behavior and removes provider upstream and pass-through environment variables.

Hardening: the root certificate key is stored in `~/.ai-proxy/root-ca.pfx` (directory `0700`,
file `0600` on Unix, optional `PROXY_ROOT_CERTIFICATE_PASSWORD`). Starting the proxy no longer
adds the root to any OS certificate store unless root trust is enabled. The system proxy is set
to the endpoint the proxy actually listens on, and a failed set stops startup. Proxy library
errors reach the host log. A failed compression forwards the original body, and bodies of
unknown length are not compressed.
