# 0.16.0: Claude launcher and proxy diagnostics

- Add `ai-proxy claude` to launch Claude Code through an already-running proxy with its CA file and current project header. Arguments, terminal streams and exit status pass through; other custom headers and bypass entries are preserved.
- Make `ai-proxy -h` and `--help` print command help without starting the proxy or changing certificate trust.
- Restore information-level compression summaries with reducer path, part count, body byte counts and byte ratio for direct forwarding and CCR.
