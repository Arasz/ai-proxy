# 0.27.2: harness arguments need no separator

`ai-proxy harness claude --resume <id>` failed with `Unknown option 'resume'`, because only arguments after a literal `--` reached the harness.

Arguments after the executable now go to it unchanged. The launcher keeps its own `--proxy`, `--ca-file` and `--help` when they come before the first forwarded argument. `--` still works, and it is how to pass one of those three to the harness, for example `ai-proxy harness claude -- --help`.

PR: [#117](https://github.com/Arasz/ai-proxy/pull/117).
