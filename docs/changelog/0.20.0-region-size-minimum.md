# 0.20.0: the size minimum applies to a whole region

Compression used to check each fragment of a tool result against its kind's minimum. A long
document that split into many short Markdown and prose fragments mostly went unreduced: in the
11,107 character prose sample, 26 of 35 fragments were skipped as too small.

Now the proxy compares the whole region with the minimum of the kind that holds most of its
characters, then reduces every fragment. A region under that minimum is left alone, as before.
A kind that is switched off, such as directory listings, is still never reduced. A region that is
a single fragment behaves exactly as it did.

On the prose sample, all 35 fragments now reach their reducer instead of 9. The characters saved
stay at zero for now, because the Markdown and prose reducers do not remove anything from that
text. The change makes the minimum correct; it does not make that sample smaller.
