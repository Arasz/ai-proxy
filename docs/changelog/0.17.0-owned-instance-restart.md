# 0.17.0: Restart an owned running instance

- Add `ai-proxy --restart`: gracefully stop the same-user instance in the selected data directory, wait for its process to exit, then run the replacement in the foreground. With no owner, start normally.
- Preserve actual proxy and API ports unless configuration explicitly overrides them. Serialize competing starts so a losing restarter cannot stop the replacement.
- Add `PROXY__DATADIRECTORY`, `PROXY__CONFIGURESYSTEMPROXY`, and `PROXY__TRUSTROOTCERTIFICATE` for runtime isolation. Allow proxy port zero and publish the actual bound port.
- Compare Linux process identity using exact kernel start ticks, avoiding inconsistent runtime wall-clock conversion across processes.
- Keep root help free of server startup, including `--restart --help`. Detect held legacy system proxy markers before touching certificates and report occupied known endpoints without terminating unrelated processes.
