# 0.15.2 - Public CA file and installed-tool setup

Starting ai-proxy writes its public inspection certificate to `~/.ai-proxy/root-ca.pem`,
alongside the private PFX. Clients that take a CA file, including Claude Code through
`NODE_EXTRA_CA_CERTS`, can trust that public certificate. The PEM contains no private key.

The README now covers installing and starting the tool, checking the local API, connecting
Claude Code with explicit proxy and certificate settings, and using the gain and MCP commands.
The token icon appears at the top of the README and ships in the NuGet package.
