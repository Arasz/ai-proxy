# 0.5.0: configurable proxy port

**Released:** 2026-10-23
**PRs:** #27

`PROXY_PORT` sets the loopback port the proxy listens on and the port written into the system
proxy setting, so ai-proxy can run beside another proxy that holds `8080`. Unset, it stays `8080`.

A `PROXY_PORT` that is not a whole number from 1 to 65535, including an empty one, stops startup
with an error naming the variable; it never falls back to `8080`. A port another program already
holds also stops startup before the system proxy setting or its crash-recovery marker is written.
