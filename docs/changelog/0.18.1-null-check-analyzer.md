# 0.18.1

The build now rejects `ArgumentNullException.ThrowIfNull` on a value that nullable analysis
already says cannot be null. Rule `APGEN003` lives in `AiProxy.Generators` and runs on Core,
Storage, Code and the host. It allows the check on `T?`, unconstrained generics and code with
nullable analysis off. The 36 calls it flagged are gone.

Smaller clean-ups with no change in behaviour:

- Five classes now use primary constructors: `SqliteCaptureStore`, `SqliteContentStore`,
  `CompressionExecutor`, `ContentRouter` and `TitaniumSystemProxyRegistrar`.
- `ProxyLease` is an instance class passed to the proxy lifetime, so tests can supply their own.
- `TitaniumProxyService` requires a `TimeProvider`.
- `CcrPlan.MessagesPath` reuses `ProviderEndpoints.AnthropicMessagesPath`.
- The MCP tool inventory generator emits nothing for a project with no tools.
