# 0.28.1: a safer aph launcher

`aph.cmd` named `ai-proxy` by its full path, which `cmd.exe` misreads when the path has a non-ASCII character such as `ł`, or a `%`. It now finds the tool beside itself.

`ai-proxy shortcut` also leaves more files alone. A file counts as ours only if its second line is the exact marker, so a script that merely mentions the marker is not replaced. A symlink at the `aph` path is refused, and a non-executable `ai-proxy` earlier on PATH is skipped.

If you created `aph` on 0.28.0, run `ai-proxy shortcut` again to replace it.
