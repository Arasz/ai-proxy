# 0.14.1 - Trust the root certificate once, not three times per start

On macOS, every start asked three times to approve a change to the keychain trust settings,
although the ai-proxy root certificate was already trusted.

- **Cause.** Startup trusted the certificate through Titanium's `EnsureRootCertificate(userTrustRootCertificate: true, ...)`,
  which also told Titanium to trust it again on every later check. The proxy start and the system-proxy
  registration each run such a check, so `security add-trusted-cert` ran three times.
- **Fix.** Startup now loads the certificate, checks whether the user trusts it, and trusts it only when
  not. Titanium's later checks no longer trust it again. A trusted certificate starts without a prompt;
  the first run, or a run after the trust was removed, asks once.
